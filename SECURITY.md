# Güvenlik açığı bildirimi

Güvenlik açığını, exploit ayrıntılarını veya gerçek kullanıcı verilerini herkese açık issue olarak paylaşmayın. Repo sahibi GitHub'da özel güvenlik bildirimi (private vulnerability reporting) etkinleştirmişse Security sekmesinden özel bildirim gönderin; etkin değilse repo sahibiyle özel bir kanal üzerinden iletişime geçin.

Etkilenen sürümü, Windows ve Python sürümünü, tekrarlama adımlarını, olası etkiyi ve varsa düzeltme önerisini paylaşın. Örneklerde gerçek parola, anahtar, kasa dosyası veya kişisel verileri kullanmayın. Bu dosya bir yanıt süresi veya desteklenen sürüm taahhüdü oluşturmaz.
